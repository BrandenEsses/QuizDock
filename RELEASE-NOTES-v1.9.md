# QuizDock v1.9

- Adds a six-second Daily Double reading phase after the wager and before the five-second response timer.
- Adds explicit sound-enablement controls for host and TV screens so browser autoplay restrictions are visible instead of silently suppressing effects.
- Keeps the v1.8 TV sequence: contestant identity while answering, the submitted response during judging, and submitted plus correct responses at reveal.
- Adds a packaged image clue to the built-in sample game so native media rendering can be tested without an external service.
- Documents that generated boards remain text-only unless media is explicitly supplied, avoiding invented URLs and extra API cost.
