# QuizDock v2.2

## Visual board designer

- Open the designer directly from the landing page without creating a room.
- Build Jeopardy, Double Jeopardy, and Final Jeopardy from host-friendly form controls.
- Begin with a blank 6×5 game or copy the room's current game into the designer.
- Add or remove categories and clues within QuizDock's supported limits.
- Attach optional native image, audio, or video URLs plus attribution metadata.
- Upload an existing QuizDock JSON game, download a work-in-progress JSON file, or validate and load the design directly into the room.
- Create a host room only when **Start room with this game** is selected.
- Preserve incomplete designs as downloadable drafts while requiring complete, valid content before play.
